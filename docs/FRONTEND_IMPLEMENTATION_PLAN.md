# AGROSV — Frontend Implementation Plan (`docs/FRONTEND_IMPLEMENTATION_PLAN.md`)

Sequential execution plan across Stages 1–11:

| Stage | Scope | Key Deliverables |
|-------|-------|------------------|
| **Stage 1** | Audit & Planning | `docs/FRONTEND_AUDIT.md`, `FRONTEND_ARCHITECTURE.md`, `FRONTEND_IMPLEMENTATION_PLAN.md`, `FRONTEND_API_INTEGRATION_MAP.md`. |
| **Stage 2** | Design System & Primitives | `styles/tokens.css` (light/dark, forest green, earth, water, semantic status), `styles/global.css`, `EvidenceBadge`, `MetricCard`, `SourceAttribution`, `UncertaintyPanel`, `EmptyState`, `ErrorState`, `LoadingState`, SVG Chart system (`ChartFrame`, `SvgLineChart`, `SvgBarChart`). |
| **Stage 3** | Application Shell & Home | `AppContext`, `routes.ts`, `AppShell` (desktop sidebar, mobile drawer, breadcrumbs, theme/profile switches, `GlobalSearchModal`, `OfflineIndicator`, contextual help drawer), `HomeDashboard` wired to live `/api/health`, `/api/territory/departments`, `/api/economics/production/statistics`, `/api/monitoring/alerts`, and selected location summary. |
| **Stage 4** | Central Geospatial Experience | `AgriculturalMapExperience` using MapLibre GL JS: El Salvador boundaries (departments + toggleable historic municipalities), raster overlays (hillshade, slope, relief) with opacity control, OSM vector layers (waterways, water bodies, roads, settlements, infrastructure), WFP/OSM markets overlay, climate reanalysis station markers, coordinate/location click probe, integrated `LocationProfileDrawer` calling `/api/engines/environmental`, `/api/monitoring/status`, and `/api/economics/logistics`. |
| **Stage 5** | Phase 5 Territory & Environment | Unified Territory & Resources module with 5 tabs: Territorial Profile, Soil Explorer (0–30 cm properties, USDA texture, limitations, missing horizons), Hydrology Explorer (surface water vs. D8 watershed vs. Budyko P−ET0 vs. unavailable groundwater), Climate Explorer (reanalysis points, monthly seasonality, ETCCDI indices, drought percentiles, explicit non-SPI/non-station disclaimers), Integrated Environmental Profile + interaction constraints. |
| **Stage 6** | Phase 6 Agricultural Intelligence | Searchable Crop Catalog (22 crops, REF/NAC/GAP status), Crop Detail view, Suitability Evaluator (`S1/S2/S3/N` + limiting factors via `/api/agriculture/suitability`), Interactive Agricultural Calendar (planting windows, phenology stages, stage water risks via `/api/agriculture/calendar` & `/phenology`), Crop Simulation & Water Balance (`agrosv_water_balance` via `/api/agriculture/simulate` + adapter status matrix for AquaCrop/WOFOST/DSSAT). |
| **Stage 7** | Phase 7 Monitoring, Risks & Alerts | Satellite & Spectral Index Explorer (`/api/monitoring/sources`, `/indices`, custom band calculator, STAC search plan), Crop Health & Stress evaluators, Pest & Disease Catalog & risk evaluators (`/api/monitoring/pests`, `/diseases`, `/pest-risk`, `/disease-risk`), Mobile-first Field Observation form with offline draft queue (`/api/monitoring/field-observations`), Risk calculators & Alert Center (`/api/monitoring/alerts`, lifecycle transitions, verification events). |
| **Stage 8** | Phase 8 Agricultural Economics | Production Dashboard (CAP 2025 + World Bank + production assessment), Guided Cost Calculator with Salvadoran units (`mz`, `ha`, `qq`, `kg`, `t`, `USD`) via `/api/economics/costs/aggregate` & `/budgets`, Price Explorer & Historical Trends (WFP El Salvador via `/api/economics/prices` & `/prices/history`), Market & Logistics Explorer (`/api/economics/markets`, `/logistics`, `/market-access`), Profitability & Break-even Calculator (`/api/economics/profitability`, `/break-even`), 15 Configurable Economic Scenarios comparison (`/api/economics/scenarios`, `/scenarios/run`). |
| **Stage 8b** | Research, Data & Nemotron | Data Catalog & Quality (`/api/data/catalog`, `/quality/reports`), Science v1 & Offline Department ZIP downloads (`/api/v1/offline/{dept}.zip`, `/api/v1/validation/policy`), Onboarding Crosswalk 2023 lookup (14/44/262), Socio-Agricultural Nemotron Explorer (`/api/social/nemotron/agricultural`, `/api/socio/scenarios`, strictly labeled synthetic). |
| **Stage 9** | Offline-First & Optimization | `manifest.webmanifest`, Service Worker (`public/sw.js`), `offline/storage.ts` & `offline/sync.ts`, Vite code-splitting (`manualChunks` + `React.lazy`), marker/layer memory cleanup. |
| **Stage 10** | Testing & QA | Configure Vitest + React Testing Library + jsdom; write automated tests for navigation, search, scientific provenance rendering, maps/layers, agriculture, monitoring/alerts, economics/unit conversions, offline sync, accessibility, and build/performance checks; run full backend `pytest` and frontend `vitest` + `tsc` + `vite build`. |
| **Stage 11** | Final Documentation | Complete all 13 required `docs/FRONTEND_*.md` documents grounded in verified implementation and test outputs. |
